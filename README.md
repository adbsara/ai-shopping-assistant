# 🛍️ AI Shopping Assistant

Semantic product search in Persian and English, powered by bge-m3 embeddings and Qdrant.

**Live demo:** https://huggingface.co/spaces/saraadib93/ai-shopping-assistant

## Tech stack
- Embeddings: BAAI/bge-m3 (multilingual)
- Vector database: Qdrant
- API: FastAPI + Docker
- Demo UI: Gradio on Hugging Face ZeroGPU
